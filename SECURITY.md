# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/Switchboard-SI/harnessrouter-paperclip-adapter/security/advisories/new)
for this repository. Include what you found, how to reproduce it, and the impact you expect.

We aim to acknowledge reports within 3 working days and to agree a fix and disclosure timeline
with you.

## Supported versions

Security fixes go into the latest released version.

## Scope

In scope: this adapter's handling of API keys, request and response data, retries and logging.
Vulnerabilities in HarnessRouter, Paperclip or `harnessrouterjs` themselves should be reported
to those projects.
